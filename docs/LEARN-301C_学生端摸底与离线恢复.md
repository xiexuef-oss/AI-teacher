# LEARN-301C 学生端摸底与离线恢复

2026-11-17。接续LEARN-301B服务端，增加首页“三题摸底”入口和学生专用页面。当前工程原型使用自编样题，不代表学科诊断量表或真实教学有效性验证。

## 行为与恢复边界

- 新建、开题和明确结束均使用生成的契约请求。发送前，固定请求体、幂等键、轮次/题目版本写入本人本机记录；写盘失败不发送。刷新或重启只GET，不自动POST；学生明确恢复时使用原请求和原键。
- 服务器返回成功后先保存原操作回执，再GET最新工作区；历史回执不会覆盖新一轮的当前进度。已知回执在刷新失败后保留，恢复只做GET与本机确认，不再POST。
- 同一工作区版本的迟到GET不能擦掉已知首份提交；低版本GET不回退缓存。损坏、未知版本、归属不符及校验和不一致的记录拒绝使用并保留原字节。缓存可供本人查看，但未刷新时不允许新建或开未绑定题目。
- 已绑定题目复用原作答页的本机草稿、笔迹和提交机制。诊断层不再存一套答案或判题。结束本轮不删记录；停止重试只停本机重试，不承诺取消已发送请求。
- 账号/凭据及激活代次共同隔离A→B→A：原响应可落入原学生历史，不能给新身份切换页面、应用结果或自动确认。明确业务版本冲突保留原命令为拒绝，不把旧请求改成新版本再发；未知网络/服务错误保留可恢复状态。
- 本机命令历史暂限200条/2Mi字符，达到上限拒绝新增并保留现有记录。计划及本机命令尚未纳入完整导出/删除流程；不自动裁剪或清空历史。更长历史的归档需结合导出与Q-07留存政策。
