# V1.3 决策清单

## 已明确（不得再作为未决问题）
- D-01 首发地区：**四川 CN-51、重庆 CN-50**。
- D-02 当前模型策略（用户于2026-11-16更新）：**DeepSeek Flash 为当前接入模型**，统一 AI Gateway 管理；base URL 为 `https://api.deepseek.com`，密钥只引用环境变量 `DeepSeek_ANTHROPIC_AUTH_TOKEN`。官方及实际鉴权模型列表确认模型 ID 为 `deepseek-flash`。原百炼优先策略由本次指示替代，百炼与火山不作为自动启用的回退。
- D-03 客户端：Flutter；iPadOS/Android 平板优先，兼容手机；以手写及交互图解为重点。
- D-04 首发科目：数学、物理、化学，主要高考题型基础覆盖，样板题深度教学。
