# DRAFT-301A 本机冲突留档与恢复

范围：学生端本机能力。没有新增或更改 API，没有创建服务端独立作答；DRAFT-301B 服务端独立副本仍未完成。副本不自动上传，不是跨设备备份，清除应用数据或卸载仍可能丢失。

冲突发生时，将当时本机稿和服务器返回的草稿作为完整一对写入带 user/question 隔离的恢复记录，保存待解决状态。选项、填空、小问、实验格子、证明步骤（含空步骤与依据）和笔迹一起保留。解决前再留档最新双方；写入失败拒绝替换，保持冲突和原内容，云端不写。重启读取待解决记录，恢复冲突横幅并阻止自动同步；本机主草稿与留档按保存时间恢复较新内容。

恢复入口位于作答页提示区，按保存时间列出本机副本。学生选择恢复时，先保存当前内容，然后将副本放回当前编辑区，不恢复副本旧有的服务端 attempt 关联，不立即上传；之后继续编辑或主动重试才按现有规则同步。未解决冲突仍需学生选择，恢复副本不能绕过冲突门控。每次留档追加，不静默裁剪旧学生内容；空间不足时明确失败。

恢复记录有独立版本。未知版本、解析失败和题目不匹配时保留原记录并拒绝覆盖，不清空或自动修复。该题处于冲突阻断状态，避免把异常记录当作不存在。普通草稿已有的损坏原文保护逻辑保留。

同一存储实例、同一用户与题目的写入排队，失败不堵死后续重试。解决与恢复期间按钮禁用；异步操作捕获本地编辑版本，等待期间学生继续输入会使旧操作停止应用，避免迟到结果覆盖新内容。恢复记录仍采用项目已有 shared_preferences 单键整体写入，并非数据库事务；系统强制终止、底层存储损坏和跨进程写入仍需要后续持久层升级与设备验收，不能把测试框架结果称为真机无损验收。

复审修复：待解决／损坏记录的阻断状态独立于网络保存状态，断网不能清除阻断或启动草稿自动重试，联网不自动采用或上传任何一方。明确选择时才允许恢复远端关联并解除相应门控。恢复期间不能提交，提交／同步／连接在途也不能启动恢复，异步落地再次校验阶段及作答身份。恢复记录追加携带持久代际；解决只在同题写队列内匹配预期代际后清除 pending，旧实例不能清掉新冲突，普通副本恢复也不能把已有 pending 直接设为 false。这是同存储实例内的代际校验，不是跨进程锁或跨设备事务。
