# 首发区域与高考内容适配规范（V1.3）

## 已冻结决策
- 首发地区：四川省（CN-51）、重庆市（CN-50），配置项不得根据定位推断；用户手动选择，后续可修改并保留历史答题归属。
- 产品首发学科：数学、物理、化学；生物、其他科目不在本次内容承诺内。覆盖三科学习的主要客观题、书面解答、证明、实验与综合题交互模式；题量和审核完成度按实际发布清单公示。
- 地区化必须同时考虑**考试年份**、**科目**、**考试制度版本**、**教材版本**和**实际题目来源**。省份不等同于教材版本；不得凭省份自动指定教材版本或假定两省卷完全一致。
- 题库只可发布有权使用且经审核的题目；历年真题标注来源、年份、地区/适用考试类型、版权及审校信息。不得以自编模拟题标称真题。

## 首次使用引导（最多三步）
1. 选择地区（四川 / 重庆）。
2. 选择年级（高一 / 高二 / 高三）及主要学习科目（多选）。
3. 教材版本：可选择“暂不清楚”，或通过教材封面/学校信息人工确认；不阻塞使用基础共通知识点。
考试年份默认按预期毕业年份推算，并允许修改；推算结果必须在个人设置可见且可更改。

## 数据契约
- `student_profiles.region` 保留兼容，不作为新逻辑来源；使用新增 `region_code`（CN-51/CN-50）、`exam_year`、`exam_scheme_code`、`curriculum_version`（未知可为空）。
- `exam_region_rules` 按 (`region_code`,`exam_year`,`subject`,`scheme_code`) 版本化管理并经审核才生效，存储考试形式、题型映射、发布生效日期及官方依据来源；不得在代码中硬编码“永远 3+1+2”。
- `question_region_applicability` 区分试题**原始来源地区**与**推荐适用地区**，并包含 `exam_year_from`, `exam_year_to`, `review_status`；默认无地区标记的自编基础题可通过课程映射供通用练习，但不得认定其代表某地区高考风格。
- `question_curriculum_mappings`：题目与教材/章节映射按审校版本管理，避免更换教材后破坏历史记录。
- 学生历史会话保存学习时地区及考试年份的快照；切换地区后历史成绩不得迁移覆盖。

## 推荐题目筛选逻辑
1. 先判断年级、学科、知识点、难度、审核状态和版权许可。
2. 选择地区适用题；不足则使用“全国通用基础题”，界面需明确来源及适用性；严禁伪装为四川/重庆真题。
3. 学生可按“高考真题 / 模拟题 / 基础母题 / AI 生成变式”筛选；AI 变式审核或自动校验未通过不得发放。
4. 所有区域规则、教材映射均需后台维护、版本审批和审计日志。

## 验收
- 四川、重庆各有独立配置，切换后训练推荐可变化，已产生会话历史不变。
- 教材版本未知仍能学习，并提示补充设置。
- 真题来源信息可追溯，地区规则无依据不得启用，不能跨年份误用。
- 学生不可通过修改客户端参数访问其他学生数据。
