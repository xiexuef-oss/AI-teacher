# DATA-303E 本机拍题记录导出

2026-11-17。本地工程验收完成；完整个人备份、删除及全项目目标保持开放。

## 使用与范围

“我的 → 隐私与数据 → 导出本机拍题记录”，资料加载失败时也可使用。无需联网，保存JSON，可查看但暂不支持导入或据此自动重试。

复用既有文件保存组件，沿用学生角色、请求捕获的身份对象、跨异步读取的身份切换检查、保存取消/错误反馈及32MiB字节上限。新入口使用明确的命名构造，不叠加可互相冲突的布尔选项；既有本机练习与服务端导出入口行为不变。

`ScanWorkspaceStore.exportSnapshot()`复用现有串行、按学生校验的只读read，不创建工作区、迁移、确认回执、重试、续期或删除数据。导出明确列出以下字段，而不打包存储目录：

- format_version=1、scope=local_scan_records、owner_id、当前工作区ID；保存组件附加导出时间。
- 全部现存工作区的文字、表达式、编辑版本、媒体/扫描引用及已有观察结果，含非当前工作区和未同步文字。
- 现存恢复命令的原键、类型、阶段、资源路径、编辑版本、已保存正文/回执、错误符号和图片摘要/大小。正文和回执复用已有生成类型校验；不将未知结果改成成功。
- 旧版草稿沿用现有只读解释，包含文字和旧扫描/媒体引用；不重建已被旧逻辑舍弃的历史，不导出旧版废弃重试键。

不含原图字节、登录信息、上传地址、内部wireFingerprint/身份激活代次或其他学生数据。即使保存的上传回执包含带签名的URL，导出也删除upload_url；原图引用不保证图片存在。未知版本、归属错误、未知字段或损坏记录整次失败，界面不输出原始错误，原数据保留。空记录明确提示，不生成伪称完整的空备份。

这不是完整设备备份：账户/资料修改、家长授权和其他恢复命令的本机范围仍需逐项处理；服务端学习记录、练习草稿、摸底记录继续使用各自入口。
