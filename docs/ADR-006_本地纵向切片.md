# ADR-006 本地纵向切片

本阶段认领 ARC-001、CON-001 的基础实现，以及 REG-001、GW-001 和客观题主流程的开发切片。以 OpenAPI 与教学事件 Schema 为契约，先增加资料接口和用例，再实现后端、Flutter 客户端和迁移验证入口。完整任务按原 DoD 验收。

## 原型决策

- Q-03 使用仅显式开启的本地身份 Mock。每个本地学生由随机 bearer 绑定，保存到客户端本地。原型仅绑定回环地址。
- Q-04A 使用网关 Mock 与规则降级。配置沿用供应商顺序，外部服务默认禁用。
- Q-05 使用自编工程样题。样题可在本地原型演示，正式题库需另行完成学科审校。
- Q-08 教材可为空。年级、预期考试年及科目允许独立选择。默认考试年基于 9 月学年起点估算。
- Q-09 地区样题标签只测试筛选，不代表官方命题规则。官方规则保持未启用。

开发 API 使用 SQLite 隔离演示状态，资料、会话快照、草稿、幂等结果随本地文件保存。MySQL 迁移单独验证，不把原型表当作生产迁移。接入 MySQL、正式授权与实机验收后方可发版。
