## 当前行为

- `GET /diagnostics` 读取本人的最近轮次及单调递增的工作区版本；无记录时不写数据库。`POST /diagnostics` 以工作区和个人资料的期望版本创建三题计划。另有按ID回看、打开计划内会话、明确结束轮次三个操作。
- 复用已发布题目与当前地区/年份的可练筛选，限定已选学科、非变式客观题，以及同年级或未标年级的题。未知学生年级不推断。候选不足三道返回422，不换地区、不拿主观题凑数。不代表教材章节覆盖或经审校的能力测验；工程样题继续显示工程样题来源。
- 计划固定题目版本、摘要和资料快照。开题复用普通练习会话及其现有草稿、提示、提交与幂等流程，不新建判题或笔迹系统。新建绑定递增工作区版本；重复打开返回原会话。未打开题目换版或资料修改返回409，保留记录，等待学生明确结束或确认下一步。
- 仅各绑定会话的首份已提交作答参与本轮计数，其他会话及后续重答不替换它。`uncertain/pending/error` 不算对错；借助提示单独计数。没有掌握度、分数、排名、提分推断或新增家长内容入口。
- 工作区写入、会话绑定和幂等回执在同一事务提交。同键重放原响应而非最新进度；客户端必须随后GET当前工作区。旧版本命令不自动重基。结束不删除会话、作答或草稿，旧轮次仍可按ID回看。
- 迁移仅追加 `016_diagnostic_plans.sql`，三张表为 `diagnostic_runs`、`diagnostic_states`、`diagnostic_items`。原始作答仍在原有学习记录中；新计划元数据尚未纳入DATA-303B导出。删除仍待Q-03/Q-07，依赖见DATA-304。
