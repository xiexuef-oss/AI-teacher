# ADR-016 结构化题目导入

状态：已采纳（2026-11-15）。范围：docs/07 的内容制作与审核入口，任务 CONTENT-IMPORT-001。

## 决策

审核后台提供“导入题目”：选择或粘贴单题 UTF-8 JSON，预览题干、来源和使用依据，明确确认后提交。
可下载的示例是自编工程样题，未经学科审校。文件选择限制为 1 MB；不会执行文件中的代码或 HTML。
完整请求格式由 `contracts/openapi.yaml` 的 `AdminQuestionImport` 定义，示例在
`apps/admin_web/public/examples/question-import.json`。

`POST /admin/question-imports` 仅 reviewer/admin 可用，角色检查先于请求体校验。
来源限自编、教材授权、公开许可、已授权真题；来源名称和使用依据不可为空，真题分类必须声明真题授权。
这只是来源声明的结构检查，不能代替版权和学科人工核验，不代表 Q-05 已冻结。AI 变式暂不支持。

每次创建全新题目及第 1 版 draft，提交者取自 token。文件不能设置 ID、作者、审核状态和地区适用标记。
解法审核标记全部清空，导入者不能自己二审或上线。来源记录跟随题目保存，导入动作写入审核历史。
后续编辑、独立二审、发布使用既有流程，学生在发布前不可见。

复用现有版本内容保存逻辑；未知知识点、跨学科知识点、重复解法及结构错误拒绝保存。
与编辑草稿一致，其他内容校验问题允许暂存并在详情显示，二审和发布前必须修正。
答案的自动泄题标记按现有算法补齐，证明关键构造仍须人工提供。

写入与幂等记录在同一事务内。网络失败重试同一内容沿用同一幂等键；成功后按钮禁用，提供打开草稿入口。
不同幂等键代表新的导入，不做语义去重。

## 验证与边界

API 测试覆盖草稿可见性、作者隔离、独立二审到发布、幂等、非法来源、知识点错误不落库、
不合格内容保存后不能二审，以及下载示例可导入。后台组件测试覆盖 JSON 错误、来源确认、失败重试与成功状态。

此阶段不读取原始试卷目录，不支持 PDF/Word/图片识别切题，不做批量导入、附件上传或版权自动判定。
真题识别导入仍依赖 Q-04A、Q-05；原始文件的使用范围未被本项改变。
