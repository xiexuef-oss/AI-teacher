# V1.4 自动化教研中心开发计划

以现行仓库为主工程。参考 `docs/V1.4` 中的教研中心独立包、整合包及其 `11_v14_actual_integration.md`、`CF_tasks.md` 和验收表。整合包从 004 迁移起步，当前主工程已到 034，新增表应使用主工程下一个可用编号并单库验证升级与回退。

## 开发顺序

| 任务 | 交付与验收 |
|---|---|
| CF-001–003 | 后台入口已接通现有导入与审核。035 迁移、显式岗位检查、本人岗位查询及平台管理员分配与撤销界面已接入。各教研业务操作的契约和权限随对应任务验收。 |
| CF-004–006 | 复用文档解析和现有知识节点，补来源授权地域、范围、期限与证据，按题型关联知识点。教研任务独立幂等、预算、重试和取消；验证未授权或过期材料不能进入生成。 |
| CF-007–010 | 依次实现母题、L1–L4 变式、快速解法及独立质量校验。生成结果进入候选草稿，保留来源与母题版次。无合适快解时保存 `not_applicable`；校验失败须可回查。 |
| CF-011–012 | 扩展审核台显示验证证据，保留禁止自审。发布人复核许可，发布与审计在同一事务写入现有题库版本，撤回可追溯。 |
| CF-013–015 | 学生端、学习 Agent 和纸包读取授权发布版本，验证旧纸包仍使用固定版次；验证反馈匿名化、三科实测和试点发布证据。 |

学校私人材料保持在学生私域。文档上传和资料目录盘点属于来源准备，外部生成与正式发布继续执行现有 Q-04、Q-05、Q-07 决策和审校门槛。现有审核账号可以访问工作台，后续教研操作由服务端检查对应岗位。

CF-001 的岗位检查要求审核后台身份和对应岗位记录，四个岗位分别授权，现有平台管理员账号也需显式岗位记录。岗位校验及迁移静态回归共 31 项通过。隔离 MySQL 8.4.13 空库安装和历史升级两项通过，见 `var/v14-cf-role-migration.xml`。

教研中心页面已接入本人岗位查询。接口按登录身份查询，学生与家长返回 403，响应禁止缓存，撤回记录后再次请求即时反映变更。平台管理员可通过幂等接口为有效后台账号分配或撤销岗位，权限变化写入审计。测试确认旧分配回执不会恢复已撤销授权。接口及岗位单测共 6 项通过。

CF-004 已新增 036 迁移和题源许可查询。许可按题源、用途和地区独立记录，要求证据引用与有效期，过期或撤回即不通过。数据库拒绝登记学生私域类别。许可与迁移静态测试共 29 项通过，隔离 MySQL 空库安装及历史升级两项通过，见 `var/v14-cf-source-migration.xml`。后台登记、审校与撤回操作，以及生成、打印和外发调用的接入仍待实现。

CF-004 的题源登记 API 与后台界面已接入，仅显式获授编辑岗位的后台账号可登记标题、来源类别和文件 SHA-256。支持选择本地文件计算摘要或手动输入，提交只包含元数据。幂等重试复用登记回执，撤销岗位后立即拒绝新请求和旧请求重放。登记写入审计，不创建许可。登记、岗位和许可专项共 5 项通过。许可审校和撤回接口待接入。

CF-004 许可审校和撤回 API 与后台表单已接入，要求显式教研审核岗位，禁止自审。核准须填写证据与期限，撤回立即使对应地区和用途失效；重放旧核准只读回执。审核员按题源 ID 可查询地区、用途、日期、凭证及当前许可状态，响应禁止缓存。后台教研专项 4 项通过。生成、打印和外发联动仍待接入。

CF-005 的 037 迁移已新增题型草稿及知识点关联，题型可关联现有知识节点，区分主要、前置和辅助关系。草稿创建服务校验同学科与重复关联，并记录审计。单测与迁移静态测试 28 项通过，隔离 MySQL 空库安装与历史升级两项通过，见 `var/v14-cf-question-types-migration.xml`。已接入编辑岗位的草稿创建 API，同一幂等键复用回执，不同请求遇重复编码返回 409。题型查询、后台界面与后续审校仍待实现。

CF-005 教研工作台已接入题型草稿创建表单，按学科读取现有知识节点并选择关联关系。编辑和审核员可按 ID 读取题型状态、规格、适用范围及知识点关联。查询接口禁止缓存。独立审核员可在题型详情填写意见、核准草稿或停用已核准题型，系统记录审核意见和状态变化。重放核准回执不会恢复停用题型。接口与契约测试共 66 项通过，后台全量 440 项通过。

CF-006 已追加 038 迁移和独立教研队列状态变更。租约超时可重新领取，旧租约与撤销后禁止写入结果，失败按上限延迟重试，成功结果进入待审核。队列单测及迁移静态测试共 29 项通过，隔离 MySQL 空库与历史升级两项通过，见 `var/v14-cf-job-migration.xml`。任务创建、查询和撤销接口、预算及实际工作进程待接入。

CF-006 已接入编辑岗位的题源分析入队、本人状态查询和取消。新任务要求所选地区的有效内部分析许可；重复请求复用回执，跨账号查询与取消返回 404，成功取消写入审计并使租约失效。后台可提交、按任务 ID 查询并取消未完成任务。任务、许可与契约测试共 68 项通过，后台全量 441 项通过。预算与实际执行尚待接入。

CF-006 独立命令 `uv run python tools/run_content_factory_worker.py` 已接入题源元数据分析；`--once` 只处理一个任务。执行前重新检查地区许可，失效则标记失败且不产出结果。隔离 MySQL 独立进程 1 项通过，见 `var/v14-cf-worker-mysql.xml`。任务创建者可在工作台查看元数据检查结果，读取时复核许可，失效后只返回任务状态。任务、许可、契约测试 68 项及后台教研专项 7 项通过。授权原件、正文分析和模型预算待接入。

CF-004/006 已追加 039 迁移并接入临时原件上传 API 和工作台界面。只允许获授编辑岗位的题源登记人保存与登记摘要一致的文件，并要求对应地区的原件留存许可。复用现有文件类型和大小限制，留存上限取许可到期和现有导入临时留存期的较早者。工作进程清理到期原件，撤回留存许可同时删除该地区原件。上传、许可及契约测试 67 项通过，隔离 MySQL 空库与独立工作进程两项通过，后台全量 442 项通过。正文分析与预算仍待实现。

CF-006 已接入原件正文的本地隔离提取。工作进程须同时具备内部分析、读取和原件留存许可；解析在事务外执行，写入前复核许可、原件期限和租约。只保存页数、正文字符数和待 OCR 页数。自编 PDF 真解析及解析中取消测试通过，后端相关 68 项、后台专项 8 项通过。正文知识标注、OCR、外部模型和预算仍待接入。

CF-004/006 新增解析期间撤回读取许可的回归：原件仍受独立留存许可保护，解析任务标记失败且拒绝写入结果，已有任务查询只保留元数据。原件、许可与任务专项 4 项通过，见 `var/v14-cf-revocation-during-parse.xml`。

CF-005/006 已接入本地知识点候选标注。按知识节点标题匹配自原件提取的正文，记录候选和命中页码，不保存正文，不自动建立题库关系。真 PDF 测试验证完整英文标题命中而单词子串不误命中。后端相关 68 项、后台专项 8 项通过。OCR、模型推断和预算仍待接入。

CF-006 网关数据库预算存储已支持独立教研计数。同一调用者在教研和学生业务分别累计请求及费用，平台的每日请求槽同样隔离。SQLite 与网关回归 30 项通过，隔离 MySQL 的并发限额及原子扣减 5 项通过，见 `var/v14-cf-budget-mysql.xml`。独立进程在 dev 可用 `--mock-ocr` 验证网关链路，启动时强制关闭外部调用。隔离 MySQL 三个进程场景通过，PNG 模拟 OCR 只增加教研请求量，页面仍标为待 OCR，见 `var/v14-cf-ocr-mysql.xml`。真实外部 OCR、推断与持久化费用预占、结算待接入。

当前工作树在隔离 MySQL 通过 14 项迁移与业务测试，包含独立进程读取授权 PDF、返回知识点候选及页码，见 `var/v14-cf-mysql-document-worker.xml`。全量后端 3306 项通过、176 项跳过，见 `var/v14-cf-full-backend.xml`。Flutter 794 项、Dart 契约 326 项、审核后台 442 项通过，静态检查与契约一致性通过。隔离副本中模拟绕过教研任务归属和纸包发布前题源复核，两项均被测试拦截，见 `var/v14-cf-mutation/mutation-evidence-rb6f7ag8/summary.json`。

模拟 OCR、预算隔离及撤回验证完成后，复跑契约、迁移、模型网关和教研任务相关测试，657 项通过。Ruff、后台 API 类型一致性和差异检查通过，见 `var/v14-cf-preflight.xml`。

提交前另复跑全部教研 API 测试文件，5 项通过，见 `var/v14-cf-api-final.xml`。同一版本的 Dart 契约测试 326 项通过。
