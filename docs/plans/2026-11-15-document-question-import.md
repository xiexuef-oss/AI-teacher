# PDF、Word、图片识别切题与批量导入开发计划

状态：本地原型开发与验证完成；证据及发布前依赖见 `2026-11-15-import-acceptance.md`。日期：2026-11-15。
任务组：CONTENT-IMPORT-002。承接 ADR-016 的单题 JSON 导入。

## 目标与交付流程

审核员上传多个文件 → 提取文字或识别图片 → 按题号建议切分 → 人工校对题面与答案 →
补齐题型、学科、来源和使用依据 → 批量保存为待审草稿 → 独立二审 → 发布。

支持文字 PDF、扫描 PDF、DOCX、常见图片，以及既有结构化 JSON。原始 DOC 格式单列为转换适配任务，
不能把只支持 DOCX 表述成支持所有 Word 文件。图表、公式、双栏和跨页题存在识别误差，必须可回看原文并修正。
本计划不包括自动评分、自动发布，也不扫描或默认导入仓库中约 8.4 GB 的试卷目录。

## 约束与待决项

- 复用既有身份、作者隔离、内容校验、版本记录与审核机制；导入者不能自己二审或发布。
- 所有新 API 先改 OpenAPI，再写失败测试和实现；同步 Dart、TypeScript 及真实响应样例。
- OCR 和模型结构化调用经 AI Gateway，客户端不接触厂商密钥。模型与端点走配置，示例外部调用保持禁用。
- Q-04A 未冻结前完成 OCR 适配接口、Mock 和降级；真实扫描件识别必须在配置与协议确认后验证，不能把 Mock 标为识别完成。
- Q-05 未冻结前使用自编或明确授权的测试材料，来源声明不等于版权核验；对外提供题库前明确审校负责人。
- Q-07 的原图留存、地域与供应商条款未冻结；原型仅用受控临时文件，任务清理机制可配置，不将原图长期留存策略擅自定为生产政策。
- 主观题保持 pending、自查流程不变；实验安全提示、证明依据、泄题门禁继续由现有校验守住。

## API 与状态设计草案

以下仅为设计方向，实际路径和字段以实施时的 OpenAPI 为准，不视为已实现接口。

- 新建导入任务、上传文件、查询任务与文件处理进度、取消任务。
- 查询和修改候选题，拆分/合并后更新修订号，显式确认题面、答案与来源。
- 提交已确认候选题，查询逐题草稿 ID、错误与批次统计，重试失败项。
- 写动作带幂等键；修改带预期修订号，并发冲突返回 409；同一候选题的已成功提交具有稳定映射。
- 任务状态建议：待处理、处理中、待校对、导入中、完成、部分失败、失败、已取消。
- 候选题状态独立于题库审核状态；“识别完成”不表示“已审校”。

批量提交采用逐题原子事务：题目、版本、审计及候选题成功映射一起落库，防止“已创建题目但未记成功”导致重复。
取消只停止尚未开始的工作，不删除已导入题目；已创建草稿通过现有内容流程处理。
任务归属及团队共享规则实施时写进契约；原型默认仅创建者可见，跨账号不可见返回 404，角色检查优先。
本地新增 proto_ 表不进入生产迁移；如需生产表，迁移只追加。

## 实施位置

- `contracts/openapi.yaml`：任务、候选题、批次与错误契约。
- `services/api/tutor_api/`：导入路由、存储、解析、切题、任务执行与批量提交服务。
- `services/ai_gateway/`、`config/`：OCR/结构化任务适配、校验、预算、配置与审计。
- `apps/admin_web/`：上传队列、进度、校对工作台、批量结果及重试。
- `tests/`、`tools/e2e/`：自编测试材料、失败恢复与真实后端联调；不提交未授权原始试卷。
- 解析库与转换器需先做小样验证、核验许可证和部署条件，再锁定版本；此计划不预先选定外部 OCR 服务。

## 测试与交付门禁

测试材料至少包含文字 PDF、扫描 PDF、混合 PDF、DOCX 段落/表格/图片、DOC、PNG/JPEG、双栏、跨页题、
独立答案页，以及损坏/加密/超限文件。使用自编题构造预期切分结果，识别与学科内容分别验收。

重点覆盖：任务越权、上传限制、解析超时、OCR 低置信度、答案错配、校对保存冲突、重启恢复、取消、
部分失败重试、幂等结果丢失后重试、成功项不重复创建、草稿不可见、自审被拒及内容不合格不得发布。
抽取文字和原文件内容一律不执行；文件预览不加载文档外部资源。

按 AGENTS.md 先证明测试因功能缺失失败，再实现；完成后运行后端/网关/契约测试、ruff、后台测试/类型检查/构建、
Dart 契约生成检查与样例导出、Flutter 与 Dart 门禁；关键规则变更执行变异检查。
浏览器联调新增独立数据库流程，不使用演示库。环境依赖缺失必须列为未完成验证，不标全绿。

## 分批可用标准

1. 第一批：文字 PDF/DOCX 提取、人工切题校对、批量 JSON/候选题导入，可在不启用外部模型时使用。
2. 第二批：图片与扫描 PDF OCR、跨页和答案配对建议；真实识别需完成 Q-04A 前置确认与授权样本验证。
3. 第三批：DOC 转换兼容与复杂版式优化、失败恢复和规模限制验证；完整范围以各阶段验收记录为准。

不承诺未经测量的准确率或开发天数。201 阶段完成解析/OCR 小样后再估算工期，真实 OCR、授权与留存决策单独列依赖。
