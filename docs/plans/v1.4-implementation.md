# V1.4 实施计划

以当前仓库为实现基线，以 V1.4 PRD 和 acceptance.csv 为需求与验收索引。公开接口先改根目录 OpenAPI，再写测试和实现，最后重新生成客户端契约。迁移从当前最大编号之后追加。

| 顺序 | 交付 | 验收 |
| --- | --- | --- |
| 1 | R01 学习设置与预算，R05 持久任务、取消和重试 | 零预算、旧设置兼容、重复投递、租约恢复和等待学生 |
| 2 | R02 双 PDF，R04 短码与手选回收，先用自编题与人工确认 | 两版原子发布、学生版不泄题、旧版可回收、幂等、实际打印 |
| 3 | R03 私域学校材料上传、识别候选与校正 | 文件限额与隔离、拆合续页、分离教师分、确认后才产生证据 |
| 4 | R04 批量照片和二维码，R06 复测和证据更新 | 混包和模糊待确认、未知不推进、校正替换旧证据、打印任务去重 |
| 5 | R07 版本化周报，独立解析授权、缓存及端到端验收 | 上海时区、补交修订、撤销生效、Android/iPad 与纸笔全流程 |

正式题库需记录来源与独立审校，管理员可分配审核；学校材料保留在学生私域。模型遵守 D-02 和现有网关门控。解答、实验和证明维持 pending，自查不产生自动评分。解析授权与当前家长周汇总授权分别处理。

对首发地区各抽取一组 PDF 与 DOCX 空白卷，并在隔离解析进程中逐题比对。2025 四川物理卷有 12 个唯一题号的归一化文本一致，另有两份文件都重复出现的题号 1、2、3。2013 重庆理科数学卷中，两种格式的 22 个题号均可对齐，1 题文本相同，9 题文本相似度低于 0.7。报告保留源文件摘要、题号与比对结果，见 `var/v14-source-inventory/regional-pdf-docx-comparison.json`。图形、公式和重复题号仍须对照原件，报表只用于待审材料核对。

复核四川物理卷发现，重复的 1–3 实际来自试卷开头的作答说明。切题边界增加单项、多项及非选择题标题识别，说明仍保留供人工复核。原 PDF 与 DOCX 复跑后均得到 15 个无重复题号的候选，归一化文本逐题一致。见 `var/v14-source-inventory/sichuan-physics-instructions-comparison.json`；图形、公式和正式题源授权仍待核验。

同卷解析定位实测使用 PDF 解析卷分别配对 PDF 和 DOCX 题面。在两条路径中，15 道题均保留原候选，其中 12 道给出唯一来源位置，3 道因解析侧重复题号列出待核对的位置。不改写题面、不填结构化答案。DOCX 解析卷触发 `media_limit`；本次使用 PDF 原件保留现有资源上限。见 `var/v14-source-inventory/sichuan-physics-answer-pairing.json`。

DOCX 解析卷超出内嵌媒体数量上限时，后台可在同一隔离进程约束下退回仅提取文字位置。保留原文件，界面提示对照原件核查图片与公式。该路径不读取媒体内容、不送 OCR、不生成答案候选，解包与文本上限仍生效。含 230 张内嵌图像的四川物理 DOCX 解析原件复验得到 15 道题的位置提示，12 道唯一、3 道重复，题面保持原样。见 `var/v14-source-inventory/sichuan-physics-docx-answer-text.json`。

同一批原件另通过审核后台上传 API、持久任务工作进程和回读接口复验。两份文件均就绪，任务进入 `needs_review`，15 个题号仍为 12 个唯一位置及 3 个重复位置，无自动确认或自动填答。普通题面 DOCX 超过相同媒体上限仍失败。见 `var/v14-source-inventory/sichuan-physics-docx-worker-verification.json`。

Ubuntu WSL2 实际 bubblewrap 环境复验 Word 解析卷的文字回退：正常限额下保留文字且不返回图片引用，超过解包上限时返回 `unpacked_limit`。包含此用例的隔离集成测试共 14 项通过，见 `var/v14-docx-answer-linux.log`。

真实题源试跑选用 2008 年四川理科数学非延考区空白卷 PDF。隔离导入工作流生成 23 个切题候选，均未确认，任务进入 `needs_review`。题号 1–22 各出现一次，另有首个无题号片段供人工核对。第 10、17–21 题各保留了两页来源。待核对公式、题面完整性及解析对应关系后再整理为草稿。

同卷解析 PDF 试跑确认 22 个题号在解析文件中均出现多次。复跑已验证各题均显示匹配数和最多三个解析来源位置。解析文件排除在题面候选之外，全部题号保留人工配对。

真实 Word 试跑覆盖同卷旧版 DOC 和一份天津数学空白卷 DOCX。两份最初均触发 `media_limit`，天津卷包含 147 个 WMF 条目。现已跳过不支持栅格预览的 WMF/EMF 并标注原件核对，保留 ZIP 条目、解压大小和其余媒体的上限。复跑得到 DOC 的 21 个和 DOCX 的 28 个候选，仍存在漏号、重复号和公式缺失，需要人工核对。

分离图形文本框及有明确边界的作答说明后，天津 DOCX 与四川 PDF 均识别第 1–22 题且各一次。四川 DOC 转换后恢复第 19 题，文本层仍无第 16 题的明确题号，需对照同卷 PDF 补核。公式仍须人工对照原件。
