# ADR-013 实验题：数据表、安全提示、不评分、提交后对照参考数据

状态：已采纳（2026-11-13）。范围：PRD P0 第 3 条里"实验题带数据表"和 §5 里"审核实验安全提示、高风险实验不可给现实操作诱导"这一块的诚实版本——
学生能读数据表、把留空的格子填上、写文字小问，提交之后把自己填的数和参考数据并排对照；**不自动评分**。
后端、契约、Flutter 学生端、审核后台都有改动；**没有迁移**（数据表和安全提示存在题目版本的 JSON 列里）。

## 为什么还是"不评分"

和 ADR-011 同一个理由：Q-06（主观题评分细则及人工复核流程）没有冻结，原型阶段的处理方式是"低置信度弃判，不冒充官方阅卷"。
实验题看起来像"填数"，更容易让人以为可以直接比对——但真实的实验数据本来就有误差，"0.4"和"0.400"、"2.0"和"2.00"
在有效数字上不是同一回事，参考值也只是一组示范数据。比对数字、判对错，再去排"错题复测"，比不评分更糟。
所以这一版和解答题一样：系统如实说"这道题不自动评分"，把**参考数据放在学生填的数旁边**，再给一张不带分值的要点清单，由学生自己对照。

## 决策

**1. 题面。** `QuestionContent` 新增两项：
- `data_tables`：数据表列表（至多 5 张），每张表有 `key`、`title`、`columns[{key,label,unit}]`、`rows[{key,label,cells[{col,text}]}]`。
  格子的 `text` 是文字（题目给定的数据，只读）或 `null`（**留空，由学生填写**）。表、行、列的键只用字母、数字、下划线（1~16 个字符），
  所以格子的键 `表键.行键.列键` 不会有歧义。
- `safety`：`{level, notes[]}`。`level` 是 `low` / `medium`（契约里还保留着 `high` 这个取值，服务端**不收录**，见决策 6）；`notes` 1~8 条，每条不超过 200 字。
  非实验题没有这两项（`data_tables` 是空列表、`safety` 是 `null`），选择题、填空题、解答题带了它们，程序校验会指出来。

格子的字段叫 `text` 而不是 `value`：已有的测试规定题目载荷里任何地方都不能出现名为 `value` 的键（那是答案的键），
这条规则保护的是"题面里不带答案"，宁可改字段名，也不放松它。**留空格子的参考值不在题面里**，只在提交之后随自查给出。

**2. 作答形状。** `AnswerPayload` 新增 `cells: [{table, row, col, value}]`（`value` 至多 40 字）。实验题只用 `cells` 和 `parts`（文字小问，同解答题）：
同时带 `selected_options` / `blanks` / `text` 返回 422（`field: answer`）；格子必须是题目**留空**的格子——填了题目给定的格子、不存在的格子、
同一个格子填两次，都是 422（`field: answer.cells`）；选择题、填空题、解答题带 `cells` 同样 422。
**提交必须有内容**：至少一个格子有字、或一个小问有字、或草稿里有笔迹（规则同解答题），否则 422（`field: answer`）。可以只填其中几格。

**3. 评估结果。** 与解答题完全一致：`state=pending`、`outcome=undetermined`、`is_correct=null`、`review_required=true`、`feedback` 为空，
会话事件是 `uncertainty`，`reason_code=subjective_self_check`（教学事件 Schema 不用改，原因码在 ADR-011 里已经有了）。
**填得和参考数据一模一样也不判对**——有单测专门守着。实验题不进任何正确率分母、不排复测、不参与薄弱点判断，也**不算"没能判定"**。
`grading.SUBJECTIVE_MODES = ("written", "experiment")` 是这一条规则的唯一出处：自查、今日任务的排序、学情、家长周报都引用它，
不再各自写 `== "written"`——以后加第三种主观题型时只有一处要改。

**4. 对照自查。** 沿用 `GET` / `PUT /attempts/{attempt_id}/self-check`（现在解答题和实验题都能用，别的题型 409 `self_check_not_applicable`）。
`SelfCheck` 新增 `reference_cells: [{table,row,col,value}]`：题目里每个留空格子的参考值，**只在作答提交之后才给**（提交之前 409
`attempt_not_submitted`，和要点同一道门）；解答题和没有数值格的题给空列表。参考值与要点一样取自**会话开始时固定的那个题目版本**，
题目之后被修改，不影响这份作答的对照。`rubric.points[].part` 可以指向小问的键、**数据表的键**（针对整张表）或 `null`（针对整份作答）。
**不是评分**：参考值只让学生并排看，响应里仍是同一句 `disclaimer`，`summary` 仍然只有三档的个数。

**5. 题库与程序校验。** `services/api/seed/questions/experiment.yaml`：物理两道（纸带数据测加速度、伏安法测电阻）、化学一道（酸碱中和滴定），
都是 `type: experiment`、`answer_mode: experiment`；每道有两张表（数据与结果）、5~6 个留空格子、2~3 个文字小问、2 条安全提示、8~9 条自查要点、三层不泄题的提示。
`answer.value` 是一个扁平字典：小问键 → 参考文字，`表键.行键.列键` → 参考值。`content_seed._check_experiment` 是入库与审核后台共用的程序校验：

- 安全提示必须有，`level` 只能是 `low` / `medium`，`high` 被指出来；`notes` 不能为空；
- 表、行、列的键合法且不重复，每行恰好给每一列一个格子，给定的格子文字不超过 40 字；
- **每个留空格子都要有参考值**（`answer.value` 的键必须恰好是"小问 + 留空格子"），参考值不超过 40 字；
- 小问的键不能和数据表的键相同（自查要点靠它们指向各自的部分）；至少要有一个留空格子或一个小问；
- 要点只有 `key/part/text` 三个字段（带分值会被指出来）；**每个有留空格子的表、每个小问至少有一条要点**；
- **必须自己列泄题标记**（文字答案推不出自动标记）；另外，**数值型的参考值（至少 3 个字符）会自动加进泄题标记**——
  提示、换种讲法和模型输出里不能出现这些数，否则就是把留空格子的答案直接说出来了。

样题的数据靠独立重算核对：纸带算相邻点平均速度和加速度、伏安法对读数求电阻平均值、滴定对体积求平均并代入 `c(HCl)=c(NaOH)·V(NaOH)/V(HCl)`；
这只能保证自洽，**没有学科审校**，数据是工程编的，不是真实实验记录。

**6. 安全提示与高风险实验。** PRD §5 要求"审核实验安全提示""高风险实验不可给现实操作诱导"。这一版的处理是：
每道实验题必须带安全提示（没有就过不了校验，也就上不了线），学生端把它放在题干正下方，**每次都显示**，并明说"这是纸面练习，不是操作指导"；
`high` 级别的实验**不收录**（程序校验拒绝；审核后台里把级别改成 `high` 可以保存成新版本，但"程序校验"会指出来，通不过审核）——
因为"高风险实验怎么审、怎么防止给出现实操作诱导"没有专项审核流程，现在不假装有。三道样题的级别都是 `low`，
内容是读数据、算结果的纸面练习，不描述操作步骤。
**安全提示内容好不好，仍然要审核员判断**：程序只能保证"有、不空、级别合规"，没有一个单独的"安全提示已确认"字段或步骤。

**7. 学情、今日任务。** `ProgressSummary.subjective` 现在数解答题和实验题两种（字段名不变，改名是破坏性变更，所以只改了描述）：
`attempts`、`self_checked`、三档要点各有几条；仍然没有比例。家长周报的 `written_attempts` 同理——只说提交了几份，不进比例。
`estimated_minutes`：实验题 `10 + 2×难度`（要读表、算数、填数据）；新题和薄弱点补练**先推可以自动判定的题**，解答题和实验题排在后面；
练习页的题型筛选新增"实验题"。

**8. Flutter 学生端。** 题干下面是安全提示卡（警示色，带"低风险 / 中等风险，注意防护"标签和固定的一行说明）。作答区是数据表：
表头带单位；题目给定的格子是文字（公式用 `MathText` 渲染），留空的格子是输入框（数字键盘、至多 40 字、有读屏标签"某表，某行，某列，请填写"）；
表格的排版：栏够宽时撑满栏宽，各列按最小宽度的比例分（有输入框的列最小 96、给定文字的列 72、行标签列 80，字体放大时按倍数放大）；
栏比表格的最小宽度还窄（窄屏、大字体）时，表格在表内横向滑动、不截断，表格下面有一句"表格比这一栏宽：左右滑动可以看到后面的列。"。
一行的名字（读屏标签、自查对照里都用）：有行标签就用行标签；没有，就用第一列的文字（纸带那道题里是 AB、BC……）；第一列是留空的格子或没有文字，才写"第 N 行"（`experimentRowName`）。
有文字小问就复用解答题的多行输入框。**格子随草稿一起先落本机、再同步云端**
（`LocalDraft.cells`，旧版本存下的草稿没有这一项也能读，只有格子、没有别的内容也算有内容，不会被当成空草稿丢掉）。
提交之后格子变成只读、填的内容还在，页面自动滚到"对照要点自查"卡片：最上面是**"对照参考数据"——每个留空的格子一行，并排显示"你填的"和"参考数据"**
（没填的格子写"没填"，参考值照给；每一行是行名，下面一行小字是列名和单位）。这里**没有对勾、没有红绿色、不说"对了""错了"**，只写一句"参考数据只是让你对照的，不是评分"。
要点按小问和数据表分组（"数据表：表 1 …"），其余同解答题。学情页的块改名"解答题和实验题"，家长周报里同理。

**9. 审核后台。** 审核页显示数据表（留空的格子标出来）、每个留空格子的参考值、安全提示和级别；编辑器里能改安全提示、小问、要点、参考答案，
**数据表以 JSON 文本编辑**（带格式检查和解析错误提示）；留空格子的参考值是另一个 JSON 对象（键是 `表键.行键.列键`，值是字符串），
小问的参考答案仍然在小问那几行里；要点的"所属"除了小问，还能选数据表（从表那段 JSON 里读出表的键）。
版本对比把数据表、安全提示逐行对比；修改保存成新版本时，表和安全提示都会带进新版本（有测试守着，丢了会红）。
"保存时不做程序校验"的原则不变，结果在保存后的"程序校验"里。

**10. 顺带修的一个测试脆弱点。** `parent_test.dart` 里写死了一个学生 ID，而样例由 `tools/export_dart_fixtures.py` 导出，
**每次导出 ID 都会重新生成**，所以每次重新导出样例都会让 15 个家长页测试变红。现在从样例里读这个 ID。

## 没做、没验证的

- **没有任何自动评分**：不比对数字、不给误差范围提示、不识别手写、不调用模型。以后要做，需要 Q-06 冻结评分细则与人工复核流程，再经模型网关接入，
  并且遵守同一条原则——低置信度弃判。
- **没有"媒体"和图示**：PRD 说实验题带媒体与数据表，这里只做了数据表和文字；契约里有 `attachments`，但学生端和审核后台都没有渲染它，样题里也没有图片、
  器材图、流程图或视频。化学的"流程图、图片"同样没有。
- **没有高风险实验**，也没有"高风险实验怎么审"的专项流程（决策 6）；安全提示的内容只靠审核员判断。
- **模型输出没有针对实验的安全过滤**：docs/02、docs/06 要求高风险实验内容在服务端拦截或转成安全说明、不生成危险的实操指导。
  现在网关里只有 Mock，实验题的提示、讲解都是审核过的固定文字，所以这一条没有对象可拦；**接真实模型之前必须补上**
  （现有的泄题检查 `forbidden_substrings` 只管"不能说出答案"，不管"不能教人怎么做危险操作"）。
- **数据表在审核后台里是 JSON 文本**：能改能存、有格式检查，但不是表格式的编辑器；改表的结构（加一列、删一行、把留空的格子改成给定的数据）后，
  "留空格子的参考值"里对应的键要手动改——程序校验会指出"没有参考值 / 多了参考值"，不会自动改写。
- **格子是纯文本**：不识别单位、有效数字、科学计数法；数字键盘只是输入便利，不限制内容（`0.4`、`约 0.4`、`4×10⁻¹` 都收，也都不判）。
- **自查的标记仍然没有落本机**（同 ADR-011）。
- 手写笔迹单独提交，只有后端测试覆盖，没有在浏览器里实际画过（同 ADR-011）。
- 升级前缓存在本机的题目缺少 `data_tables` 这一项，读不懂，**按"没有缓存"处理**（会重新从服务端取；断网又恰好没有新缓存时，这道题离线打不开）。
  生成的 Dart 模型是严格的，没有为一个原型阶段的缓存特意放宽。
- 样题没有学科审校；三道实验题不构成覆盖，数据是编的。
- Flutter 只在测试框架和 Chrome 里验证过；平板真机、Android、iOS 没有构建。
