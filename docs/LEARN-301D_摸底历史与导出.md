# LEARN-301D 摸底历史与导出

2026-11-17。接续B/C的三题摸底工程原型，补齐本人历史分页、已有会话回看、服务端计划导出和本机操作恢复记录导出。原始草稿导出的范围保持不变，不把本轮称为全部个人数据导出或删除功能。

## 当前行为

- `GET /diagnostics/history` 仅学生本人可读，按开始时间、ID倒序分页，默认20、最多50轮。游标是上一页最后一轮的ID，由服务端在本人范围中定位；其他学生与不存在的游标都返回相同400，不作授权。相同时间以ID区分，新插入的轮次不挤进已经翻过的后续页。
- 摸底页顶部进入历史。展开可查看本轮计数、当时的地区/年级和三题摘要；已有会话可继续或只读回看首份提交，不为旧轮次未开始的题新建作答。分页使用实际生成的请求，下一页入导航栈，返回可回到上一页。历史列表需要联网，不把加载失败当作空历史。
- “我的→导出服务端学习记录”新增可选字段 `diagnostic_runs` 与 `diagnostic_workspace`；新服务始终返回本人全部计划与当前工作区。旧导出缺失字段代表未包含这一范围，不推断为零。每轮计划及条目计入现有总记录上限；超过记录数或字节上限整份拒绝，不交付部分文件。计划不含题库答案、解析或笔迹，已有会话作答仍由原学习记录部分导出。
- SQLite导出显式开启只读快照：旧sqlite3模式下SELECT不会自动BEGIN，可能在历史读完后看到另一端新建的工作区。本轮并发测试先复现此不一致，再验证同一WAL快照；不阻止另一端继续写入。真实MySQL另验证当前REPEATABLE READ约定下的相同行为，不据此修改部署隔离策略。
- 摸底页另有“导出本机摸底记录”：`format_version=1`、`scope=local_diagnostic_records`，包括本人缓存工作区及固定原请求/幂等键/已知回执。仅命令尚未关联作答时也能导出。按生成类型和字段白名单导出，不包含token或其他学生、未知私有字段、作答与笔迹。读取不改原记录；损坏记录拒绝交付，原字节保留。文件可查看，暂不支持导入；导出不会清空本机200条/2Mi字符的恢复记录上限。
