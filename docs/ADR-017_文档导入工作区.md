# ADR-017 文档导入工作区

日期：2026-11-15。状态：本地原型实施中，最终验证见持续执行队列。

## 流程与权限

审核员从单题导入页进入 `/document-import`，填写来源及使用依据，建立任务后上传文件。
处理结果是候选题，不会直接发布；人工核对题面、答案、公式、图表和来源后，批量创建待审草稿。
作者不能独立完成自己的二审与发布，继续复用 ADR-016 的规则。
任务、原文件和预览仅 token 对应的创建者可见；其他账号统一返回 404，角色检查优先。

## 本地存储与恢复

原文件有界保存在 SQLite `proto_document_import_files`，不进入生产迁移。
任务、候选题、批次意图分别保存在 `proto_` 表；写操作有幂等键与修订号。
工作器逐文件提交检查点，通过条件租约领取任务，进程退出后可恢复过期租约。
2026-11-17补充：OCR现增加逐页检查点。调用网关前在独立短事务提交
`proto_document_import_ocr_attempts`发送标记（文件/页唯一、租约、请求摘要、trace及状态），
不保存图像、提示正文或响应；识别结果仍保存在原有到期清理的文件工作区。
结果与完成状态同事务提交。恢复时只复用输入摘要一致的已完成页；可能已发送但结果未落库、
预览或系统提示变化时，保留人工录入提示，不自动重新调用。取消、租约接管或过期后拒绝迟到结果。
这不提供供应商exactly-once保证。后续已增加显式启用的共享持久调用接线，
逐attempt预算与审计结算的当前实现及128项回归、真实MySQL和6项变异证据见COST-302；
关闭持久调用时继续使用旧invoke，生产任务存储仍待开发，不据此关闭COST-301。
批次先持久化意图，再逐题将草稿与成功映射一起提交；某题失败不回滚其他题。
响应丢失时复用原请求和原幂等键恢复；修改失败题后使用新的提交动作。
任务默认 120 分钟过期，工作器清理原文件与工作区，不删除已创建的题目。
这里的删除是数据库记录删除，不承诺磁盘安全擦除；生产留存政策仍待 Q-07。

## 解析与质量边界

文字 PDF 按页提取，DOCX 保持段落和表格顺序；DOCX 的页号表示提取片段，不是真实排版页码。
PNG/JPEG 与无文字 PDF 页进入 OCR 或人工录入路径。
图像预览只返回栅格 PNG，不执行文档脚本，也不把原文当作 HTML 渲染。
公式、媒体和阅读顺序存在损失时保留警告；题号切分与跨页合并只是建议。
独立答案区保留在原文供人工配对，不自动拼入学生题干。

OCR 经 AI Gateway，默认 `TUTOR_IMPORT_OCR_MODE=disabled`。
Mock 仅验证链路，不识别文字；空输出和不可用状态不会标为真实识别成功。
真实模型、地域、价格与协议须先满足 Q-04A；不以本地测试代替授权样本评测。

## 配置与部署边界

本地 `tools/run_dev_api.py` 显式开启工作器，其他入口默认关闭。
主要限额由 `TUTOR_IMPORT_*` 配置：单文件 10 MiB、任务 50 MiB、10 个文件、80 页/片段、
200 个候选题、提取文字 100000 字符、解压 48 MiB、图像 2000 万像素、解析 30 秒。
上传使用有界 Base64 JSON，本地原型不提供分片或大文件流式上传。

DOC 转换器默认未配置。可通过 `TUTOR_IMPORT_DOC_CONVERTER` 指定受控 LibreOffice 可执行文件；
缺失时提示另存为 DOCX。适配使用独立配置目录、禁宏和禁止外链自动更新、超时与进程树清理。
这些限制不是操作系统安全沙箱，不提供硬 CPU/内存上限或操作系统级断网保证。
对外接收不可信文件前仍需部署隔离；不能据此宣称生产安全验收完成。

## SEC-302 资源配额更新（2026-11-15）

Windows Job Object现可配置进程/整棵任务内存和累计用户态CPU硬配额，本地入口默认512MiB和20秒；外部入口默认None需显式配置。已实测超额失败与正常DOC转换。该更新替代前文“没有硬内存/CPU上限”的历史描述，但操作系统网络隔离仍未完成，仍不能称为完整生产文档沙箱。

2026-11-17：显式Linux bwrap模式已在本机Ubuntu补齐原生DOC转换；仅DOC显式配置时增加LibreOffice注册表只读挂载，普通/资源组两种模式的真实二进制DOC及中文提取均通过。Windows process模式仍无OS级断网，本更新不放开默认转换和生产部署；当前11项真实Linux及192项文档回归、3项变异证据见[SEC-302](SEC-302_解析隔离与验证.md)。
