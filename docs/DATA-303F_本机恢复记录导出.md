## 使用与范围

“我的 → 隐私与数据 → 导出本机恢复记录”。只供当前学生身份，可离线；资料加载失败时也保留入口。复用原JSON保存、32MiB文件上限、取消/失败反馈和凭据激活代次检查，没有新增网络请求、依赖、迁移或公开API。

文件scope为local_student_recovery_records，标注owner_id、format_version、导出时间、history_complete=false与consistent_snapshot=false。各存储读取沿用已有LocalSerial，不把跨资料/授权/资源读取称为同一时刻的快照。缺失的bundle保持null，不创建空bundle或迁移旧记录；都不存在时说明现存范围为空，不推断从未操作。

合并三类现存记录：

- profile：已缓存资料、旧版资料投影、尚未提交的修改、原修改基线、资料命令的原键/正文/状态及回执。只读旧版资料，不迁移；生成类型及编辑白名单过滤未知字段。
- authorization：本机学生授权摘要、生成/撤销命令及现存回执/冲突摘要。保留关联ID、版本和时间，过滤邀请码、家长ID/称呼、兑换凭证及其他身份数据；不读取家长角色的本机bundle。
- resources：本人辅导/复测原命令、来源引用、现存结果/确定拒绝、压缩后的旧回执及缓存视图。保留收到的教学事件和复测结果，不重新请求或推断状态；压缩时已经移除的内容不能恢复。重新核对资源、题目/版本、来源与事件关联，生成类型过滤未知响应字段。

不导出登录凭据、运行时activeEpoch、校验和、原图、上传地址或原始存储键。不执行命令、不清理/确认/更新数据。恢复命令默认合计上限1000，资源枚举另有1000条上限；超限、坏数据、未知存储版本或归属冲突整次失败，不返回半份文件、不裁剪原记录。

切换身份、甚至切走后再切回同一学生，也不交付旧请求的结果。保存已交给系统之后的下载文件不受应用撤回控制。JSON仅供查看，不支持导回应用或自动重试未知动作。

## 仍缺少的范围
