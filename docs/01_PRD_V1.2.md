# 01 产品需求基线 PRD V1.2

## 1. 背景、用户、价值
学生：高中数学、物理、化学学生，重点服务基础薄弱、希望提升高考解题能力者；家长：查看每周趋势，不监控每次交互；内容审校员：审核题目、解答、评分规则。第一批自用验证，未来再考虑商业化。支持 Android 平板、iPadOS，兼容 Android/iPhone 手机。平板 **横屏优先，10–13 英寸**。

## 2. 不可改变的产品原则
- 学生首页仅“开始今日学习、拍题、练习、我的”四入口；常规操作不超过三级导航。
- 一道题支持“先独立尝试 → 分层提示 → 常规解法 → 有条件的快速解法 → 变式 → 延迟无提示复测”。快速法不存在则明确不展示。
- 数学、物理、化学均支持单选、多选、填空、解答/计算、证明/推导、实验、推断/流程或综合题（取决于学科）。题型不是固定的考试卷结构。
- 题目左、草稿右的可调整双栏；草稿断网/重启可恢复；手写 OCR 必须由学生确认关键字段。
- 教学图形按“静态图 → 可调参数 → 仿真”逐级采用；所有可交互图需受控模板和数据校验。
- 独立正确率、提示次数、迁移复测优先于刷题数量；无羞辱性排名和强制连续签到。

## 3. 角色与权限
`student`: 仅访问本人数据；`parent`: 仅访问已明确绑定学生的聚合周报；`reviewer`: 审核题目与标准解；`admin`: 管理配置/审计。未授权跨账号访问返回 403 或防枚举 404。未成年人授权与数据处理依法评估，不能仅凭年龄字段自行推定法定义务。

## 4. P0 发版范围：广覆盖+样板深度
1. 启动/登录、学生基本资料、学科及年级设置（可跳过年级完善）。
2. 首页任务卡，至少含“复习旧错题、薄弱点、变式、复测”任务种类，允许跳过。
3. 题目展示：客观题单选/多选/填空，主观题多小问与公式展示，实验题带媒体与数据表。
4. 作答：客观题点击/文本；主观题平板手写草稿和文字补充；保存、撤销、橡皮擦、导出图片；识别失败提供手动输入与继续作答。
5. 拍照导入：上传单题图片 → OCR 结果确认 → 匹配题或转为待审题；不允许未经校验的 OCR 直接自动算为原题。
6. 教学引擎：独立作答、分层提示、常规解、快速解（仅白名单），图解推荐，变式/复测状态。
7. 题库与知识图谱：知识点、前置依赖、题目、来源许可、解法、技巧适用边界、评分 Rubric 与审核状态。
8. 错题自动记录；复习队列；学习分析基础版；家长周报基础版。
9. 管理后台最小审核流：题目 `draft → reviewed → published`；撤回；记录审校员和版本。
10. 性能、安全、隐私、埋点及测试门禁。

### 4.1 深度实现的样板专题
数学：函数单调性、基本不等式、数学解答题分步评分、证明题逻辑链；物理：受力分析/牛顿运动定律/基础实验数据；化学：守恒计算、反应推断、基本实验操作。各专题先配置 **不少于 5 道人工审核样板题**，仅为工程验收下限，不代表教学覆盖目标。

### 4.2 P1/P2 后置
P1：试卷批量切题、手写步骤定位增强、语音问答、可调动态图模板扩容、考前冲刺；P2：高保真虚拟实验室、复杂化学分子实时模拟、完整高中三年经审核题库、商业化支付及社交互动。V1.2 不包含排名、社交、广告。

## 5. 学科/题型教学矩阵
| 类别 | 输入 | AI 教学重点 | 必须验收 |
|---|---|---|---|
| 单选/多选 | 选项 | 排除与反例、错选漏选分析 | 多选判定规则可配 |
| 填空 | 数值、表达式、单位 | 结构化化简、等价表达式判定 | 等价性无法确认→待复核 |
| 数学解答/证明 | 手写步骤+小问 | 证明前提、逻辑链、分步 Rubric | 不夸大自动给分精度 |
| 物理计算/综合 | 方程、图、步骤 | 建模、符号方向、量纲、单位 | 量纲和前提检查 |
| 物理实验 | 表格、图示、文字 | 仪器、数据处理、误差来源 | 审核实验安全提示 |
| 化学推断/工艺流程 | 文字、图表、小问 | 物质转化、守恒、反应条件 | 反应式规则核验 |
| 化学实验/综合 | 流程图、图片、文字 | 装置操作、现象解释、安全 | 高风险实验不可给现实操作诱导 |

## 6. 核心用户故事（含验收）
- US-01：学生打开 App，无配置直接开始当前任务；首次无能力档案时启用简短诊断/按教材进度选题；断网显示已缓存内容。
- US-02：学生拍一道题，识别并确认题干之后进入同一答题页；错误识别可编辑或重拍。
- US-03：学生手写主观题，后台保存笔迹数据与缩略图；断网写入本地待同步；重复提交不会生成两次评分。
- US-04：学生点击“给点提示”，仅暴露下一层提示，不直接泄露结果；若点“完整解析”允许主动查看，并记录辅助状态。
- US-05：模型输出不可信时，不能静默标记正确；明确展示“待确认/暂不可自动评分”。
- US-06：家长只看到授权学生的聚合趋势，不看到未经学生允许的私密草稿逐笔信息。

## 7. 学习有效性与观测
独立正确率 = `无提示且未看解析的正确作答数 / 无提示且未看解析的有效作答数`；辅助正确率另算；按不同题型、难度分层统计。复测成功率、提示依赖率、变式迁移率作为辅助指标。课程、年级、地区需在诊断中关联；不保证短期提分效果。

## 8. 变更管理
V1.1 是产品意图来源，V1.2 将 API 全部统一到 `/api/v1`，资源 ID 为 UUID，时间为 UTC ISO-8601，全部事件有 `request_id`；如需调整，先修改契约、迁移与测试，再实现代码。参见 ADR。

## V1.3 产品决策补遗（优先于 V1.2 的同名描述）
首发地区冻结为四川与重庆；首发数学、物理、化学及主要高考题型，覆盖基础作答、提示、标准解法及复测。客户端依然以 iPad/Android 平板横屏、手写演算及动态图示为主。省份、考试年份、教材版本分离建模，详见 `09_首发区域与教材题库适配.md`。

AI 服务采用阿里云百炼为主平台、DeepSeek 负责复杂推理、火山引擎为备选；均从后端统一网关路由，真实模型身份和价格上线前核验，详见 `10_AI模型网关与成本治理.md`。
