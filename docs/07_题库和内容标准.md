# 07 题库制作与内容审核标准

## 1. 来源和版权
题目来源记录 `source_type`（教材授权/公开许可/自编/高考原题许可等）、`source_name`、`source_year`、`source_license`、`source_url`；没有合法使用依据的材料仅限内部核验，不得上线或对外宣称授权。

## 2. 最小题目元数据
学科、年级、教材版本、试题类别、知识点 ID、难度 1–5、考查能力、题干 LaTeX/Markdown、选项/小问、标准答案、等价规则、单位、常规解、可选快速解、技巧适用条件和反例、Rubric、素材及版权、审校状态、版本。

## 3. 题型审核
- 客观题：唯一/多选正确组合、干扰项合理性、题干歧义、数值精度。
- 填空：符号化简/等价答案容差与单位规则、有效数字。
- 解答证明：每步骤前提、适用范围、替代解法得分点。
- 物理：坐标约定、方向、单位、物理假设、极端情况。
- 化学：化学式与方程式配平、实验结论、安全边界。
- 交互图：模板参数边界和动画物理意义一致性。

## 4. 审核发布流程
`draft`（编辑）→ `reviewed`（独立二审）→ `published`（上线）→ `withdrawn`（问题下线）。提交内容的人不能作为唯一审校人；修改题干或答案后增加版本，旧版本留痕。若为 AI 生成的变式题，可先只在内部沙盒和人工审核试点中使用，正式发放前应通过至少程序校验和风险分级审核。

## 5. 样板内容集
数学：函数与单调性/基本不等式/证明；物理：受力与运动/电路/实验；化学：守恒计算/物质推断/实验。每主题至少 5 道经复核样板题；每题至少一份标准解、必要时一份快速解、2 个经检验的变式。不要提前把“AI 生成 10000 道题”作为首版验收标准。
