# AI 模型网关、路由、质量与成本治理（V1.3）

## 当前供应商策略
- 2026-11-16用户明确更新为DeepSeek Flash；原百炼优先策略由此次指示替代。地址、模型ID和密钥来源由服务端配置，当前确认值见DECISIONS_PENDING D-02。
- DeepSeek API与现有OpenAI兼容适配器可用；用户给定的密钥变量虽然包含ANTHROPIC字样，仍可作为该兼容接口的Bearer密钥使用。
- 百炼和火山配置继续保留禁用，不自动跨供应商回退。示例配置的外部调用默认禁用约定不变。
- 用户级环境密钥鉴权已验证；一次自编样例调用成功，仅代表连通与结构化返回，未产生准确率评测结论，也未确认数据地域、报价或Q-07条件。

## 统一后端 Model Gateway
Flutter/iPad/Android 客户端**绝不直接持有厂商密钥**。所有请求经 FastAPI -> Teaching Orchestrator -> Model Gateway；网关统一提供 provider adapter、密钥管理、限流、超时、熔断、日志脱敏、费用控制、JSON 校验、审计追踪。学生文本、图像需最小化传输；必要时先遮盖姓名、学校和个人标识。

### 逻辑任务类别
`ocr_extract`, `handwriting_understand`, `knowledge_classify`, `tutor_hint`, `tutor_explain`, `complex_reasoning`, `solution_verify`, `visual_spec`, `review_plan`。
默认路由映射见 `config/model_routes.example.yaml`。路由可由运营/技术后台更新并留审计记录；不得由客户端选择绕过。

### 统一调用 DTO（内部，非面向学生的公开 API）
请求：`request_id`, `student_pseudonym`, `task_type`, `input_parts`, `constraints`, `trace_id`, `cost_budget`, `privacy_policy`, `response_schema_version`。
响应：`provider`, `model_id`, `status`, `validated_output`, `usage`（输入/输出 Token 及图像计费单位若可得）, `latency_ms`, `confidence`（可空）, `review_required`, `error_code`, `trace_id`。
所有 LLM 生成的教学事件需经过 `contracts/tutor_event.schema.json` 验证；错误时返回已审核静态解析或指导学生换一种方式，禁止输出原始异常栈。

## 路由与降级规则
- 低成本优先：题型分类、常规提醒可使用低成本模型或规则引擎；已审核母题尽量直接引用内容，不重复生成。
- 数学证明、物理综合题、主观题评分冲突等走复杂推理与验证；不因模型自信就直接公布“高考标准分”。
- 图示通过白名单模板 + 受限参数协议渲染，禁止执行模型输出代码。
- OCR 低置信度、不同模型结果冲突、分步评分不确定时，必须让学生确认或显示“暂无法可靠判断”；不可擅自判错。
- 单一供应商失败：先在平台内重试限次，再尝试已获授权的备选适配器；若存在数据合规或授权限制则直接降级，不可跨服务商任意传输未成年人的原始数据。

## 成本控制
- 每请求计算预算上限，每学生每日额度与管理员平台日额度均可配置；超过限制时先使用已审核解析/规则降级，保持草稿可用。
- 采集各路由的成功率、准确性基准、平均/95分位延迟、token、估算成本和人工复核率。Token 估算仅用于预算，不可当作真实账单。
- 模型报价按配置定期核验，不将易变价格写死为长期常量；图片与缓存定价要单独处理。
- 启用服务前检查服务商条款、区域、个人信息处理协议、内容留存及未成年人相关要求。

## 质量基线（必须先建再放量）
- `evaluation/golden_dataset_manifest.csv` 用于管理内部至少 300 道经过授权、审核、标注的评测题（文件仅为模板，实际题目尚未收集）。
- 评测涵盖两地适用知识点、数学/物理/化学、选择填空、计算证明、实验与工艺流程、手写、图表题。
- 建议权重：答案推导正确 35%、错误诊断与分步评价 20%、教学效果 20%、图文/手写识别 15%、延迟成本 10%；**权重为初始可调整建议，不代表实测**。
- 重要门禁：不能提前泄题、不能将未审核内容标称真题、不能将不确定评分判为确定、不能直接泄露模型调用秘钥。

## 需要决策的上线项
真实账户及家长授权、模型具体版本及 SLA、服务商协议与数据地域、预算限额、图像保留周期、审校负责人、基准题库版权、真实平板型号。均不得由 Agent 无依据锁定。
