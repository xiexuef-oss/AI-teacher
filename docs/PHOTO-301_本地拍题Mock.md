# PHOTO-301 本地拍题 Mock

仅 local 显式开启 scan_mock_enabled 与 media_local_enabled 后可用。图片通过学生专用上传路径，内部用途 ocr_source，与审核附件隔离；永不确认为长期附件。空候选、null confidence 与 mock_notice 明确没有实际OCR。学生手输确认前不匹配，不创建练习或题库草稿。确认只精确匹配唯一的已发布自编题当前题干，歧义及未匹配返回null。图片、扫描记录沿用首次上传TTL，读取和确认不续期；启动及每次扫描请求清理到期blob与扫描文本。闲置进程到期立即拒绝访问，下次请求或重启物理清理；不是生产留存承诺。

幂等回执沿用现有本地持久回执，可能保存确认文本副本；本包TTL仅涵盖原图与扫描活动记录，不能声称所有副本均删除。到期前置归属/有效期检查阻止确认与创建重放泄露。全部副本及回执留存设计仍待Q-07。额外expressions未能验证一致性时不自动匹配。并发确认以数据库条件更新守护首次确认。

## 本地启用

在仓库根目录的PowerShell中显式设置后启动，仍仅监听回环地址：

```powershell
$env:TUTOR_MEDIA_LOCAL_ENABLED = 'true'
$env:TUTOR_SCAN_MOCK_ENABLED = 'true'
uv run python tools/run_dev_api.py
```

学生端打开拍题页，先选图，再上传临时图片、手工填写题干，明确确认后匹配；只有学生点击开始才进入已有题目。不匹配时去练习选题，不创建未经审核的新题。未启用时返回501，文字和重试键先存本机，不清空输入。

原图不写入SharedPreferences草稿；选图组件和系统可能保留临时文件，离页不保证这些文件已删除。本模块换图及离页清除自己的Flutter预览缓存和字节引用，不误删图库源文件。文字、表达式、扫描ID与幂等键按学生隔离；未知格式保留原文并拒绝覆盖。原生相机及Android丢失选图恢复仍待设备验收。

## 工程验证
