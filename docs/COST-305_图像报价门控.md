# COST-305 请求图像报价门控

状态：2026-11-17，工程实现已合入，外部供应商默认关闭不变。

原缺口是文本价格已配置但图像单价为null时，图像费用按0参与估算，仍可能调用。现在只有一个共享报价条件：外部图像请求必须明确配置 `image_unit_micros`，null表示不可用，显式0仍允许；纯文字请求不强制图像单价，本地Mock不受影响。条件用于旧invoke候选选择、单次计划准备／发送及退避后复查；不新增供应商能力标记、费用默认值或接口字段。

未报价的候选可跳过并选择已有授权且有报价的候选；只有未报价候选时安全降级。计划准备后或重试退避中撤销报价，后续不发送；已消费计划不能恢复后重用。既有在途／未知尝试不自动退款。文档OCR转人工核对，准备阶段拒绝时不留下预算、审计或本地发送标记。

报价完整不代表视觉能力、识别质量、供应商实际账单或当前价格已验证；这些仍依赖Q-04/Q-07及授权评测。通用路由可用性没有请求图像上下文，不能将“文本路由可用”解释为可以OCR。
