# 08 开发、部署、运维与隐私约束

## 1. 环境
local/dev/staging/prod 四环境；密钥由 secret manager/environment 注入，样例 `.env.example` 不包含密钥。Dev 使用 Docker Compose 的 MySQL/Redis/对象存储模拟；Staging 与生产同迁移链。

## 2. CI 与质量门禁
PR 必须经过 lint/format、Python 类型与单测、Flutter analyze/widget tests、OpenAPI linter、JSON Schema 测试、SQL migration clean install、集成测试；主干必须绿色。分支命名 `feat/TASK-ID-*`，提交需列任务 ID 与测试证明。

## 3. 观测
请求延迟、HTTP 错误率、AI 超时与回退、OCR 置信度分布、手写保存成功率、变式题核验失败数；不默认采集原始题目图片进入监控。按请求 ID 关联服务日志；对学生身份使用去标识化 ID。

## 4. 隐私与未成年人
产品上线前就服务地区咨询适用的未成年人保护、隐私、AI 内容管理与题库版权义务；收集最少必要数据、提供用户查看/导出/删除、授权撤回、家长绑定管理；明确 AI 提供辅助学习反馈而非官方阅卷。

## 5. 故障与降级
模型不可用→审核解析；图示失败→静态说明；OCR 失败→手工输入；网络断开→缓存题与本地草稿；服务数据异常→阻断提交且保留本地备份。不得在客户端直接调用模型供应商密钥。

## 6. 发布门禁
至少 Android 与 iPad 实机各一台 10–13 英寸，手机各至少一个模拟器/实机；验证设备权限、笔迹恢复、离线、账号切换、公式渲染、内存与耗电。正式发布还需完成 App Store/Android 渠道合规审查和用户隐私条款。
