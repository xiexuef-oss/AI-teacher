# 02 系统架构与设计决策

## 1. 技术栈冻结
- Flutter 稳定版（在实施时锁定具体版本到 `tool-versions`），Dart；平板自适应布局；状态管理建议 Riverpod，路由建议 go_router，具体锁版本后在 ADR 中记录。
- FastAPI + Pydantic v2 + SQLAlchemy 2 + Alembic；Python 3.12（实际生产兼容性先验证）。
- MySQL 8.0，Redis 7（缓存/短期幂等键）；对象存储（媒体和手写备份），凭短期签名 URL 上传下载。
- AI 多模态模型经 **Model Gateway** 统一调用，模型更换不影响教学事件契约。数学表达式可用 SymPy 辅助验证；公式/图形由受限模板渲染。
- 管理后台 Vue 3；开发环境 Docker Compose；生产容器化，CI 执行契约测试、迁移测试与端到端测试。

## 2. 单仓结构
```
/apps/flutter_student/
/apps/admin_web/
/services/api/
/services/ai_gateway/
/packages/contracts/        # OpenAPI 生成客户端与教学事件 schema
/packages/visual_templates/ # 白名单模板配置、参数校验
/infra/compose.yaml
/migrations/
/tests/
/docs/
/AGENTS.md
```
目录为目标项目推荐结构，本工程包本身不包含可运行源代码。

## 3. 组件和数据流
Flutter → FastAPI 鉴权/权限 → 会话/题库/作答服务 → MySQL；媒体经签名 URL → 对象存储；AI 调用由后端编排 → Gateway → OCR/LLM/符号计算/模板决策 → 严格校验 → 教学事件 → Flutter；学习事件异步写入分析。AI 服务不能直连生产数据库写入学习成绩。

## 4. 安全边界
- 每个访问校验 `user_id + role + tenant/student ownership`；后台与学生不同授权作用域；不得相信客户端传入的 student_id 作为授权依据。
- Bearer Access Token 有效期可配，Refresh Token 旋转并可撤销；凭据存系统安全存储；日志脱敏。
- 图片、草稿、学生姓名等按敏感数据处理；传输 TLS；对象私有；数据保留/删除可配置；关键操作有审计记录。
- 模型不执行任意 Python/JS/SQL；OCR/视觉素材不当成高权限指令；HTML/LaTeX 渲染限制可执行内容；图示只允许已注册 `template_id` 和参数边界。
- 生成的高风险化学实验内容在服务端拦截或转安全说明，不生成危险实操指导。

## 5. 离线策略与同步
- 题目缓存可离线浏览，手写笔迹使用 SQLite/Isar 等本地存储原子写入（具体客户端实现锁定后记录 ADR）。
- `draft_id` 为 UUID，`revision` 单调递增；上传含 `base_revision`；冲突返回 HTTP 409，保留本地版本并提示比较或新建副本，不静默覆盖。
- 队列同步指数退避，幂等键按每次提交固定；离线不提供需要云模型的 AI 自动评分。

## 6. 可靠性和容量（初始 SLO 假设）
- 非 AI API 正常网络 p95 ≤ 800 ms；静态题目首屏 p95 ≤ 2 s；AI 首事件 p95 ≤ 8 s，未满足时展示处理中/可取消（均需预发布压测验证）。
- 笔迹每 2 s 本地增量保存及应用切后台即时保存；不可只依赖云端。
- AI Gateway 超时、预算与重试策略配置化；失败时提供本地/审核解析降级，不能伪装成功。

## 7. ADR
- ADR-001：原微信小程序优先路线改为 Flutter 平板优先。
- ADR-002：统一 API 前缀 `/api/v1`，移除旧版 `/attempts` 等不带版本前缀定义。
- ADR-003：内容审核后才能进入正式题库，AI 生成变式先通过规则校验与人工抽样。
- ADR-004：自动主观题评分是**练习性反馈**，置信度不足只反馈步骤建议，不给确定分数。
- ADR-005：单仓+契约先行，任何破坏性变更须升级 API / migration 并更新测试。
